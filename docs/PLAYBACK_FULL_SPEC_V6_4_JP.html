✅ V6.3/V6.4 検証サマリー（実機測定）

Night モード低中域歪み（D1）の根治と Info 精度改善（Phase 0 A–D）を両方とも非破壊方式で実装。実機（Huawei MAR-LX2J）で NightCompressorDistortionTest 3/3 GREEN（2026-10-15 測定）

  • D1 実機ゲート低中域 THD: 60/120/250Hz で 1.120 / 0.647 / 0.322%（修正前 5.11–5.91%、ゲート <1.5%）。peak→RMS 検波化により、音量に関係なく歪まない。
  • D1 実機ゲート大音量抑制 ON-vs-OFF: −5.16 dB（ゲート ≤−4dB・Night の意図を維持）。
  • D1 実機ゲート音量非依存: 出力音量 1.0/0.3/0.05 の全段階で THD 0.532% 完全一致（コンプレッサーが音量段より前で動作している物理的証明）。
  • 性能コンプレッサーステージ +0.08%（49.4ms/60s 音声・無視可能）。既存 JVM テスト 240/0/0（V6.4 追加分を含む）。

🚀 1. コア・ネイティブNDK ＆ USB ビットパーフェクト直結パイプライン

ARM NEON SIMD 演算に最適化された 96kHz / 32-bit Float 精度マスタリング処理基盤と、AudioFlinger を完全バイパスする USB 直結 E2E ビットパーフェクト出力。

  • NEON SIMD 96kHz/32-bit Float パイプライン: 96,000Hz / 32-bit Floating Point の全マスタリングDSP処理を ARM NEON 命令で並列高速化。
  • サンプル精度 ギャップレス再生パイプライン:
    ・SinkCarrier 引き継ぎアーキテクチャ【検証済】 トラック境界でシンクを破棄せず保持。後続トラックがバッファ末尾へシームレス追記（無音隙間ゼロ）。バッファフロア 196,608 フレーム ≈ 2.048秒、SeamAudit が drained < capacityFrames で GAPLESS 判定。
    ・LookaheadScheduler 先読みプリウォーム 曲終了 5 秒前（ネットワーク状態で 5/8/12 秒に可変）に次曲を検出しデコーダーを先読み初期化。
    ・Fade-Hold 末尾排出 真の最終チャンクをフェード（最大 3ms / 288 フレーム）して全 DSP/シンク経路で排出。全トラックが正確なゼロ振幅で終了。
  • デュアルパス 絶対位相反転（0° / 180°）:
    ・DSP ON モード【検証済】 C++/NDK 層（nativeSetPhaseInverted）で ~1ms クロスフェードのノイズフリー反転。
    ・DSP OFF モード【検証済】 JavaPhaseInverter が USB パッキング直前の生 PCM を反転（ビット深度・SR 完全保持）。
  • V6.3 D1ナイトモード・ダイナミクス・コンプレッサー（RMS 検波化）:
    ・RMS フィードフォワード検波 mean-square ~5ms 平滑。1周期内でゲインが変動しないため低中域 AM 歪みが原理的に発生しない（THD 5.9% → 0.32–1.12% 実測）。
    ・契約不変 2:1 / −24dB / 20ms-300ms / −9dB フロア / ~10ms ランプトグル / kill-switch はすべて不変。無効時はビット透過パススルー（max|diff|=0 実測）。
    ・ロックフリー＆ゼロアロケーション R4 完全順守（新規 atomic ゼロ）。
  • 4点 Catmull-Rom リニアフェーズ・リサンプラー（RateConverter）【検証済】:
    ・時間対称 4 点カーネルで線形位相・プリリンギング完全排除。WAV 44.1kHz 供給粒度問題は pipelineBuf 73,728 floats 拡大で根治済み。
  • USB 直結出力モード（AudioFlinger バイパス）:
    ・DSP オフ（E2E ビットパーフェクト） SR・ビット深度・生 PCM を 100% ビットエグザクトで DAC へ直送。
    ・DSP オン（96kHz/32-bit ＆ 24bit 自動フォールバック） DAC が 32-bit 非対応時は 24-bit へ自動ダウングレード。
  • Direct NDK Isochronous USB エンジン:
    ・C++/NDK から Linux ioctl で等時性 URB を直接送信。USBDEVFS_DISCONNECT_CLAIM によるカーネルドライバ動的デタッチ／再結合。UAC1/UAC2 デスクリプタ解析。ソフトスタート・アンチポップランプ（8 チャンク ~20–50ms）。

🌊 2. 空間音響 ＆ 5x5 バーチャルアコースティック・マトリクス

🛡️ 安全ルール（R1–R5）

  • R1 Bit-Perfect: DSP OFF 時 100% Bit-Exact 直通。定常状態でゲイン変更ゼロ。
  • R2 Gapless: トラック境界のサンプル精度・位相連続。
  • R3 True-Peak: 4× FIR オーバーサンプリング + 1ms ルックアヘッドで ISP 捕捉（threshold 0.98）。
  • R4 Lock-Free: 音声スレッドに新規 lock/heap/syscall を増やさない。
  • R5 Kill-Switch: 全機能に即時 legacy 復帰導線。
