# Biscene DSP Player ユーザーマニュアル

---

## Biscene DSP Player — ご紹介

Biscene DSP Player は Android デバイスでハイレゾ音源をビットパーフェクトな環境から高度な DSP 処理付きで再生できるアプリです。

- **ネイティブ DSP パイプライン**: MediaCodec → Float32 → カスタム DSP チェーン → AudioTrack (96kHz)
- **ヘッドフォン自動校正 (AutoEq)**: 数十種類のプロファイル対応。簡単選択で最適化。
- **A/B バイパス & プリセット管理**: DSP のオン/オフを即時切替可能。お気に入りサウンドを保存/呼出。
- **UPnP / DLNA / ローカルファイル対応**: ネットワークストレージ及び Android の SAF による直接取込み再生をサポート。

## 1. クイックスタートガイド

Biscene DSP Player を起動してから再生まで、5 ステップで完了します。

| ステップ | 操作 | 説明 |
|---------|------|------|
| 1 | アプリを起動 | Android ホームから「Biscene」または「Biscène Audio System」アイコンをタップします。起動時に 5 つのデモトラックがキューに自動ロードされます。 |
| 2 | ソースを選択 | プレーヤーパネル下部の **FILES** / **QUE** / **NETWORK** ボタンから再生ソースを選びます。デモ楽曲で試す場合は何も選択せずに進んでも構いません。 |
| 3 | 再生を開始 | 中央の **▶** ボタンをタップします。DSP パイプラインが自動的に初期化され、音が出ます。再生中に緑色 LED が点灯します。 |
| 4 | ミキサー調整（任意） | 右下の **MIX** ボタンをタップして 3D フリップパネルを裏面に回転させ、イコーラル、クロスフィード、アンビエンス、ヒュームフィルタを調整します。 |
| 5 | ヘッドフォン校正（任意） | MIX パネルの **SET** ボタンをタップしてヘッドフォン校正ドロワーを開き、お使いのヘッドフォンモデルを選択すると AutoEq 補正が即座に適用されます。 |

> **ヒント**: 音量は中央のマネ歯車状ホイール（Machined Wheel）を回�/rev することで調整できます。物理的な音量ボタン（Android デバイス）も同時に機能します。

## 2. UI 概要 & 操作方法

### メインシャーシ（Main Chassis）

アプリの中央にある木製フレーム（WoodFrame）と金属パネル（MetalPanel）の 2 層構造が、ハイエンドオーディオ機器のような質感を再現します。

```
┌─────────────────────────────────────┐  ← WoodFrame（木製枠）
│  ┌─────────────────────────────┐    │
│  │    MetalPanel（金属パネル）   │    │
│  │                             │    │
│  │  [フォーマット] [出力先]    │    │  ← 上部ヘッダー
│  │  ┌─── アルバムアート ───┐   │    │  ← AlbumArtFrame
│  │  │  (校正カーブオーバレイ)│   │    │
│  │  └────────────────────┘   │    │
│  │                             │    │
│  │  ┌── 3D フリップパネル ──┐ │    │  ← プレーヤ / ミキサー
│  │  │  [PLY] Player          │ │    │
│  │  │  [MIX] Mixer           │ │    │
│  │  └───────────────────────┘ │    │
│  │                             │    │
│  │  [REP/REG]  Biscène  [PLY/MIX] │  ← 下部操作バー
│  └─────────────────────────────┘    │
└─────────────────────────────────────┘
```

#### UI パーツ一覧

| パーツ | 場所 | 機能 |
|--------|------|------|
| **WoodFrame** | 最外枠 | 木製グランビージュフレーム。アプリ全体の筐体を形成。 |
| **MetalPanel** | WoodFrame 内側 | ブラシ金属テテパネル。内部パーツを配置するベース。 |
| **AlbumArtFrame** | 上部中央 | アルバムアート表示。ヘッダーホバー時に AutoEq 周波数特性カーブをオーバレイ表示。 |
| **PlayerControls** | フリップパネル正面 (PLY) | トランスポート操作、VU メーター、音量ホイール。 |
| **MixerControls** | フリップパネル裏面 (MIX) | DSP チェーン全パラメータの調整。 |
| **MachinedWheel** | PlayerControls 中央 | 0–15 段階音量調整ロータリーダイアル。中央 PRESET ボタンでプリセットロード。 |
| **VuMeter** | PlayerControls 左右 | 20 段 LED メーター (赤→黄→緑)。ピーク + RMS に応じて動作。 |
| **BisceneLogo** | 下部中央 | ブランドロゴ。 |
| **REP / REG ボタン** | 下部左 | プレーヤーモード: トラックピン (REP)。ミキサーモード: プリセット保存 (REG)。 |
| **PLY / MIX ボタン** | 下部右 | 3D フリップパネルの正面・裏面を切替。 |

### パネル: プレーヤー (PLY)

プレーヤーモードでは以下のコントロールが表示されます。

#### トランスポートコントロール

| ボタン | 記号 | 機能 |
|--------|------|------|
| **Previous** | `<<` | 前のトラックへスキップ |
| **Stop** | `■` | 再生を完全停止し、ポジションをリセット |
| **Pause** | `||` | 一時停止 |
| **Play** | `▶` | 再生開始 / 再開 |

#### プレイバックインジケーター

- **トラック番号**: `TRACK X / Y` — 現在のトラックと合計トラック数
- **ステータス**: `[PLAYING]` または `[PAUSED]`
- **タイトル**: トラック名
- **タイムライン**: スルーバー（ドラッグでシーク可能）+ 時間表示 (現在位置 / 総時間)

#### VU メーター

- **L / R** の 2 個の 20 段 LED バー
- **色分け**: 赤 (上位 4 段) → アンバー (中位 4 段) → 緑 (下位 12 段)
- 機器非稼働時はディミmed（暗消し）

#### 音量ホイール (Machined Wheel)

- **操作方法**: 外縁をタッチしてドラッグ、またはマウスホイール
- **範囲**: 0 / 15 ～ 15 / 15 (16 段階)
- **特性**: 2 次曲線 (周波数的音量増加)
- **中央ボタン**: `PRESET` — プリセットロードダイアログを開く

### パネル: ミキサー (MIX)

ミキサーモードでは DSP チェーン全パラメータをリアルタイムに調整できます。

#### トップ機能ストリップ

| スイッチ | 説明 |
|----------|------|
| **A/B: DSP ON / A/B: DIRECT** | DSP チェーンのオン/オフ切替。DSP ON 時は緑色表示、DIRECT（バイパス）時はアンバー表示。 |
| **TUBE: 2ND HARM / TUBE: OFF** | 真空管サチュレーションのオン/オフ切替。ON 時はオレンジ色表示。 |

#### Phone Calibration カード

- **モデル名表示**: 現在選択中のヘッドフォンモデル
- **SET ボタン**: ヘッドフォン校正ドロワーを開く
- モデル名にマウスホバーまたはタッチすると、アルバムアートエリアに周波数特性カーブがオーバレイ表示される

#### DSP コントロール一覧

| コントロール | 種類 | オプション |
|-------------|------|-----------|
| **HUM FILTER (AC)** | トリプルレバー | `NONE` / `50HZ` / `60HZ` |
| **OUT EQ** | ロータリーダイアル | `NONE` / `STUDIO` / `JBL` / `PLANAR` / `LOUD` / `TUBE` / `CRYSTAL` |
| **SRC EQ** | ロータリーダイアル | `NONE` / `JAZZ` / `CLASSICAL` / `ELECTRONIC` / `VOCAL` |
| **AMB** | ロータリーダイアル + インテンシティバー | `NONE` / `HALL` / `JAZZ CLUB` / `LARGE HALL` / `CHURCH` |
| **X-FEED** | ロータリーダイアル + インテンシティバー | `NONE` / `LIGHT` / `NORMAL` |

> **ロータリーダイアル**: タップ/クリックで次のオプションをサイクル。角度インジケーターが -135° から +135° の範囲で回転。`index=0` の場合は `OFF` 表示。
> **インテンシティバー**: 10 段ピッチボタン (10% 刻み)。タップして強度を調整。

### ドロワー & モーダル

| ドロワー/モーダル | 呼び出し方法 | 機能 |
|------------------|------------|------|
| **Headphone Calibration** | MIX パネルの `SET` ボタン | ヘッドフォンプロファイル選択、リアルタイム周波数特性カーブ表示、カスタムプロファイル作成 |
| **Queue (QUE)** | PlayerControls の `QUE` ボタン | プレイリスト管理、トラック追加/削除、キュークリア |
| **UPnP Browser** | PlayerControls の `NETWORK` ボタン | DLNA/UPnP サーバーブラウズ、ライブストリームプリセット、直接 URL 入力 |
| **Local Browser** | PlayerControls の `FILES` ボタン → SAF 選択後 | SAF フォルダ内ブラウズ、マルチセレクト再生/追加 |
| **Preset Save/Load** | Mixer `REG` ボタン / MachinedWheel `PRESET` ボタン | プリセット保存、ロード、リネーム、削除 |

## 3. 機能詳細ガイド

### 3.1 ローカルファイル再生 (SAF)

Android の Storage Access Framework (SAF) を使用して、デバイス内のオーディオファイルを直接インポートして再生できます。

#### 操作手順

1. **フォルダ選択**: `FILES` ボタンをタップ → Android のフォルダ選択ダイアログが開きます。
2. **ブラウザ表示**: 選択したフォルダ内のオーディオファイルが `LocalBrowserModal` に一覧表示されます。
3. **再生**:
   - **プレイアイテム**: 個別タップで即再生
   - **PLAY ALL**: フォルダ内全曲を順次再生
   - **ADD TO QUEUE**: キューに追加
4. **複数選択**: ロングプレス（500ms）で選択モードに入り、`SELECT ALL` / 選択再生 / 選択追加が可能

#### アートワーク

- ローカルファイルの **メタデータ埋め込みアート** (MP3 ID3 APIC、FLAC METADATA_BLOCK_PICTURE、DSF/AIFF ID3、M4A covr アトム、OGG Vorbis comment) を自動抽出
- フォルダ内の `cover.jpg` / `folder.png` 等のフォルダアートにも対応
- アート抽出は非同期で行われ、再生をブロックしません

#### 対応拡張子

> `.mp3`, `.wav`, `.flア`, `.flac`, `.m4a`, `.aac`, `.ogg`, `.opus`, `.aiff`, `.aif`, `.alac`, `.wma`, `.dsf`, `.dff`, `.m4b`

### 3.2 ネットワークストリーミング (UPnP / DLNA)

UPnP / DLNA メディアサーバーから直接ブラウズしてストリーミング再生を行います。Android のネイティブ `MediaCodec` デコーダーを使用し、WebView のセキュリティ制限を回避します。

#### 3 つのタブ

| タブ | 説明 |
|------|------|
| **HOME SERVERS** | Wi-Fi 上の DLNA サーバーを SSDP 自動検出。手動 IP 入力も可能。 |
| **LIVE STREAMS** | 事前定義されたライブストリーム 6 つのプリセット。 |
| **DIRECT URL / IP** | 直接的な HTTP ストリーム URL または M3U プレイリスト URL を入力。 |

#### HOME SERVERS タブ

- **自動検出**: アプリ起動時に Wi-Fi サブネット上の UPnP サーバーを SSDP でスキャン（15 回ポーリング、400ms 間隔）
- **手動追加**: IP アドレス + ポート + コントロールパスを入力
- **サーバーテンプレート**: Synology(5000)、MinimServer(9000)、Volumio(50004)、MiniDLNA(8200)、Jellyfin(8096)、Plex(32400)
- **コンテンツブラウズ**: ContentDirectory:1 SOAP プロトコルによる階層ブラウズ
- **フォルダ操作**: フォルダ内再生、全曲再生、キュー追加

#### LIVE STREAMS タブ

| ストリーム名 | アーティスト | ジャンル | URL |
|-------------|-------------|---------|-----|
| SomaFM Groove Salad | SomaFM San Francisco | Ambient / Chill | `https://ice1.somafm.com/groovesalad-128-mp3` |
| SomaFM Secret Agent | SomaFM San Francisco | Lounge / Jazz | `https://ice1.somafm.com/secretagent-128-mp3` |
| Radio Swiss Classic | Radio Swiss Classic | Live Classical | `https://stream.srg-ssr.ch/m/rsc_de/mp3_128` |
| Radio Swiss Jazz | Radio Swiss Jazz | Live Jazz | `https://stream.srg-ssr.ch/m/rsj/mp3_128` |

#### DIRECT URL / IP タブ

- **タイトル**: 表示名
- **URL**: HTTP/HTTPS ストリーム URL または M3U/M3U8/PLS プレイリスト URL

#### M3U プレイリスト解析

- `#EXTINF` タグからタイトルとアーティストを抽出
- `#EXTM3U` ヘッダー検出
- 相対 URL をベース URL で解決

### 3.3 DSP 機能

Biscene DSP Player は、以下の 6 つの DSP ステージを搭載したマルチチェーンプロセッサを提供します。すべてのパラメータは**リアルタイム**に変更可能です（トラックの再起動不要）。

#### DSP チェーン処理順序

```
[入力音源]
    │
    ▼
1. A/B バイパススイッチ ──► [DSP パス]   or   [Bypass パス (Direct)]
    │
    ▼
2. AC ヒュームフィルタ (15Hz ハイパス + 50/60Hz ノッチ, Q=30)
    │
    ▼
3. ソース EQ (3 バンド パリンコフィルタ)
    │
    ▼
4. 出力 EQ (4 バンド パリンコフィルタ)
    │
    ▼
5. ヘッドフォン校正 (最大 10 バンド AutoEq + プリアンプ)
    │
    ▼
6. 真空管サチュレーション (WaveShaper, 2 次高調波)
    │
    ▼
7. クロスフィードマトリックス (ダイレクト + クロス, 900Hz LPF)
    │
    ▼
8. アンビエンス / コンボイバーリバーブ (ドライ/ウェット, Freeverb エンジン)
    │
    ▼
9. マスターサフィティゲイン (アンビエンスヘッドルーム)
    │
    ▼
10. ビリウッドリミッター (DynamicsCompressor, 閾値 -0.5dB, 比 20:1)
    │
    ▼
11. マスターボリューム (0–15 段, 2 次曲線)
    │
    ▼
[出力: VU メーター Analyser]
```

#### EQ (イコーラル)

| 種類 | バンド数 | プリセット | 説明 |
|------|---------|-----------|------|
| **Source EQ (SRC EQ)** | 3 バンド | `NONE` / `JAZZ` / `CLASSICAL` / `ELECTRONIC` / `VOCAL` | 音源のジャンルに最適化された音色補正 |
| **Output EQ (OUT EQ)** | 4 バンド | `NONE` / `STUDIO` / `JBL` / `PLANAR` / `LOUD` / `TUBE` / `CRYSTAL` | 出力デバイス/音色に最適化された補正 |

#### ヒュームフィルタ (Hum Filter)

AC 電源ノイズ（50Hz/60Hz とその高調波）を除去します。

| 設定 | 機能 |
|------|------|
| **NONE** | フィルタ OFF (ハイパス 1Hz, ノッチ 1Hz で実質バイパス) |
| **50HZ** | 15Hz ハイパス + 50Hz ノッチ (Q=30) |
| **60HZ** | 15Hz ハイパス + 60Hz ノッチ (Q=30) |

> **使用例**: 家庭の AC 電源から発生するブーン音や地下鉄の機器騒音を抑制するのに最適。デモトラック 5「50Hz AC Hum Test」で確認できます。

#### クロスフィード (Crossfeed)

ヘッドフォン再生時の「内向き」感を軽減し、スピーカーに近い自然なステレオ像を再現します。

| 設定 | 直接ゲイン (dB) | クロスゲイン (dB) | 説明 |
|------|----------------|------------------|------|
| **LIGHT** | 0 → -1.8dB | -46.8 → -15.6dB | 軽いクロスフィード |
| **NORMAL** | -1.5 → -3.9dB | -16.8 → -11.4dB | 標準クロスフィード |
| **NONE** | 0dB (直結) | -∞ | 完全バイパス |

インテンシティ 0–100% で強度調整可能。900Hz 低域通過フィルターを介してクロス信号を処理。

#### アンビエンス / リバーブ (Ambience / Convolver Reverb)

4 種類のホール/ルームシミュレーションから選択。IR (インパルス応答) とシンセティック生成のハイブリッド。

| 設定 | IR ファイル | シンセティックパラメータ | 説明 |
|------|------------|------------------------|------|
| **HALL** | `/ir/hall.wav` | 時間 2.0s, decay 2.0s | ホールの自然な反響 |
| **JAZZ CLUB** | `/ir/jazz_club.wav` | 時間 1.2s, decay 3.5s | ジャズクラブの密閉反響 |
| **LARGE HALL** | `/ir/large_bottle_hall.wav` | 時間 2.4s, decay 1.5s | 大ホール |
| **CHURCH** | (フォールバック: hall.wav) | 時間 2.5s, decay 1.1s | 教会の響き |
| **NONE** | なし | なし | リバーブ OFF |

ドライ/ウェット比はインテンシティ 0–100% で調整。0% の場合はドライのみ、100% で最大ウェット。

#### 真空管サチュレーション (Tube Warmth)

WaveShaper を使用した 2 次高調波歪み回路。

| パラメータ | 値 |
|----------|-----|
| **WaveShaper** | tanh ベースカーブ + 2 次高調波 |
| **Drive** | 0.5 (0.35 から強化) |
| **2 次高調波比** | 15% |
| **オーバーサンプリング** | none (96kHz ナイキストマージンにより不要) |

> **ON** 時: アンバー/オレンジ色表示 + `TUBE WARMTH` バッジ。音に温みと深みを与えます。

#### A/B インスタントバイパス (A/B Instant Bypass)

| 状態 | 表示 | 機能 |
|------|------|------|
| **DSP ON** | 緑色 (Play ボタン点灯) | フル DSP チェーン適用 |
| **DIRECT** | アンバー色 | DSP バイパス、ネイティブ DAC 直通 (ビットパーフェクト) |

> **ヒント**: A/B を切替えながら音を比較することで、DSP 効果の違いを瞬時に聴き比べできます。

### 3.4 ヘッドフォン校正 (AutoEq)

AutoEq ベースの 10 バンドパリンコフィルタエンジン。ヘッズフォンの固有周波数特性を補正し、フラットな参照音場を実現します。

#### デフォルトプロファイル一覧

| # | プロファイル ID | モデル名 | ブランド | ターゲットカーブ | プリアンプ (dB) | バンド数 |

#### 校正の仕組み

```
[再生音源]
   │
   ▼
1. 較正 (Calibration)
   お使いのヘッドフォン固有の周波数レスポンスに逆特性を適用し、
   Harman Flat Reference に初期化。
   │
   ▼
2. 再較正 (Recalibration)
   フラットにした音に、ターゲット機種の周波数特性を重畳。
   │
   ▼
[最適化された音質で出力]
```

#### 操作方法

1. **プロファイル確認**: MIX パネルの `Phone Calibration` カードに現在のモデル名が表示されます。モデル名にマウスホバー（またはタッチ）すると、アルバムアートエリアに周波数特性カーブがオーバレイ表示されます。

2. **プロファイル切替**: `SET` ボタンをタップ → Headphone Calibration ドロワーが開きます。一覧からモデルを選択すると即座に DSP フィルタへ反映されます。

3. **カスタムプロファイル作成**:
   - ドロワー内の **`+ CREATE / IMPORT PROFILE`** ボタンをタップ
   - **AutoEq テキストインポート**: `ParametricEQ.txt` の内容を貼り付けると自動解析
   - **手動編集**: 最大 10 バンドの周周波数 (Fc)、ゲイン (Gain)、Q 値を個別設定
   - カスタムプロファイルは `localStorage` に永続保存されます

4. **リアルタイムカーブプレビュー**: ドロワー内に周波数特性グラフが表示され、マウスホバー時にプロファイルを即座にプレビューできます。

### 3.6 ガプレスキュー & トラックピン (REP ボタン)

#### ガプレス再生 (Gapless Queue Advance)

- 次のトラックは **再生中** にエンジン内でプリキューされます (`queueNextTrack`)
- トラック終了時に自動的に次のトラックが即座に開始されます
- ネイティブパイス（HTTP/UPnP）では `PCM stall watchdog` によるバッファ管理

#### REP (Track Pinning)

REP ボタンはプレーヤーモードでトラックのピン（ブックマーク）機能を提供します。

| 操作 | 結果 |
|------|------|
| **REP ボタンタップ** | 現在のトラックをピン留め。次回アプリ起動時にこのトラックから再生が開始されます。 |
| **ピン留め中** | ボタンに緑色が点灯。`SET` と表示される 1.6 秒間一時点灯。 |
| **ピン留め解除** | ピン留めされていないトラックを再生中に REP を押すと、ピンが移動します。 |

> **ヒント**: ライブラリを再生中に REP を押しておけば、アプリを再起動しても中断した場所から再生できます。

#### Queue Drawer (QUE)

| 機能 | 操作方法 |
|------|----------|
| **キューを開く** | PlayerControls の `QUE` ボタン |
| **トラック再生** | 任意のトラックをタップ |
| **トラック削除** | 各トラックの `🗑` アイコン |
| **キュークリア** | ヘッダーの `🗑` ボタン |
| **ファイル追加** | `+ ファイル追加` ボタン (複数選択可能) |
| **フォルダ追加** | `+ フォルダ一括追加` ボタン (webkitdirectory) |

### 3.7 VU メーター & 診断

#### VU メーター仕様

| 項目 | 仕様 |
|------|------|
| **チャンネル** | L / R ステレオ (2 個独立) |
| **セグメント数** | 20 段 (Top: Red / Mid: Amber / Bottom: Green) |
| **解析ノード** | AnalyserNode, fftSize=256, smoothing=0.65 |
| **レベル計算** | Peak × 0.7 + RMS × 1.5 を正規化 |
| **非活性時** | ディミd（暗消し） |

#### 診断情報

Web Audio コンテキストの状態に応じて以下の情報が内部ログに記録されます:

| ログタグ | 内容 |
|----------|------|
| `PCM level` | dBFS ピーク/ルート平均レベル (5 秒間隔) |
| `PCM buffer stats` | アンダーラン/オーバーランブロック数 |
| `AudioContext dead` | コンテキスト再構築通知 |
| `PCM stall` | 30 秒間ポジションレポートなし → 停止 |
| `Native DSP live update` | ネイティブ DSP パラメータライブ更新 |

#### スタックリフレッシュ (Amber ボタン)

MixerControls の右下... ではなく、App.tsx の `handleRefreshStack` によって内部的に呼び出されます。以下の状況で役立ちます:

- DSP 設定が反映されない場合
- 音声が途切れる、ノイズが発生する場合
- ネットワーク切断後の復帰

## 4. トラブルシューティング

### 4.1 問題: 音が出ない (No Sound)

| 確認項目 | 対処方法 |
|----------|----------|
| **DSP バイパス状態** | MIX パネルの `A/B` ボタンを確認。`DIRECT` になっている場合は `DSP ON` に切替。 |
| **音量** | MachinedWheel を右に回して音量を上げる。0/15 では何も聞こえません。 |
| **デバイス音量** | Android の物理音量ボタンを上げる。MediaSession によりデバイス音量が連動します。 |
| **再生停止中** | `▶` ボタンで再生を開始。キューにトラックがない場合は `FILES` または `NETWORK` から追加。 |
| **Web Audio コンテキスト** | アプリを一度終了し、再起動。`handleRefreshStack` (内部) がコンテキストを再構築します。 |

### 4.2 問題: トラックがスキップする / 再生が途切れる (Skipped Tracks)

| 確認項目 | 対処方法 |
|----------|----------|
| **ネットワーク遅延** | Wi-Fi 信号強度を確認。UPnP サーバーのレスポンスが遅い場合、`pcmStreamActive` がタイムアウトします。 |
| **DSF/DFF デコード** | DSD 音源はネイティブ `DsfDecoder` でデコードされます。ファイル破損の場合はスキップされます。 |
| **バッファアンダーラン** | ログに `underrunBlocks` が記録される場合、ネットワーク帯域不足またはデバイス負荷が高い可能性があります。 |
| **ガプレス前倒し** | 次トラックは再生中にプリキューされます。キューが空の場合は自動停止します。 |
| **再起動** | `■` (Stop) → 再度 `▶` で再生をやり直すと解決することがあります。 |

### 4.3 問題: アルバムアートが表示されない (Missing Artwork)

| 確認項目 | 対処方法 |
|----------|----------|
| **ローカルファイル** | ファイルに埋め込まれたメタデータアート (ID3 APIC, FLAC PICTURE, M4A covr) を自動抽出します。アートがない場合は `cover.jpg` / `folder.png` をフォルダに配置してください。 |
| **UPnP/DLNA** | ネイティブプロキシ (`AndroidUpnp.getProxyUrl`) 経由でアートを取得します。サーバーがアートを提供していない場合はデフォルト画像が表示されます。 |
| **Web 環境** | HTTPS ページから HTTP アートへの混在コンテンツがブロックされる場合があります。Android APK ではネイティブプロキシにより回避されます。 |
| **遅延ロード** | 大きいリストでは `IntersectionObserver` による遅延ロードが機能します。スクロールして画像が表示されるまで待機してください。 |

### 4.4 問題: DSP 設定が適用されない (DSP Not Applying)

| 確認項目 | 対処方法 |
|----------|----------|
| **A/B バイパス** | A/B スイッチが `DIRECT` になっている場合、すべての DSP がバイパスされます。`DSP ON` に切替えてください。 |
| **ネイティブパス** | HTTP/UPnP 再生時はネイティブ `NativeDspChain` が使用されます。`updateDsp` によるライブ更新が失敗した場合は、トラックを再生し直してください。 |
| **ヘッドフォンプロファイル** | `Bypass (No Calibration)` が選択されている場合、AutoEq フィルターはすべて 0dB です。実際のヘッドフォンモデルを選択してください。 |
| **Web Audio コンテキスト** | コンテキストが `suspended` 状態の場合、`initAudioContext()` による再開が必要です。物理的なボタン操作（▶）により自動的に `resume()` が呼ばれます。 |
| **Android 10+ ハマック** | WebView コンテキストが HAL によって閉じられる場合 (`closed` 状態)、アプリは自動的にコンテキストを再構築します。 |

### 4.5 問題: プリセットが保存されない (Presets Not Saving)

| 確認項ITEM | 対処方法 |
|----------|----------|
| **ストレージ容量** | `localStorage` が制限を超えた場合、保存が失敗します。ブラウザのストレージ設定を確認してください。 |
| **プライベートブラウジング** | プライベート/シークレットモードでは `localStorage` が無効です。通常モードで使用してください。 |
| **ストレージキー** | プリセットは `biscene_dsp_presets_v2` キーで保存されます。カスタムプロファイルは `biscene_custom_headphone_profiles` キー。 |

## 5. キーボード / ハードウェアコントロールリファレンス

### ハードウェア音量ボタン

Android デバイスの物理音量ボタンは `MediaSession` によって `setNativeVolume` にマッピングされます。

| ボタン | 機能 |
|--------|------|
| **音量アップ** | `setNativeVolume({ volume: factor² })` — マスターボリューム段階上昇 |
| **音量ダウン** | マスターボリューム段階低下 |
| **音量装着** | 0/15 でミュート相当 |

> **音量カーブ**: 2 次関数 (factor²) を使用。物理 0% = 数学的 0%、物理 100% = 数学的 100%。

### ハードウェアコントロール (ヘッドフォン)

| 機能 | 対応状況 |

| **ヘッドフォンボタン (Previous)** | ✅ `handlePrevTrack()` |
| **ハードウェア DSP スイッチ** | ❌ なし (アプリ内 UI で切替) |

### キーボードショートカット
