核心差別化機能

1. ビットパーフェクト・ハイレゾ再生 (全形式)

形式 デコーダ出力 内部処理 出力 ビットパーフェクト
FLAC/WAV 16bit PCM_16BIT → Float32 正規化 96kHz Float32 OK
FLAC/WAV 24bit PCM_32BIT (Right-aligned 24bit) アライメント自動検出→正規化 96kHz Float32 OK 業界初相当
FLAC/WAV 32bit PCM_32BIT / Float32 直通 96kHz Float32 OK
DSF (DSD64/128) DSD→PCM (Boxcar decimation) 96kHz リサンプル 96kHz Float32 ~ DSD→PCM変換段階で不可避
MP3/AAC/OPUS... PCM_16BIT → Float32 正規化 96kHz Float32 OK (ロスレス相当)

技術的ポイント:

  • convertToFloat32Array() における 実データからの 24bit アライメント自動検出 (符号拡張ヒューリスティック)
  • srcBits ヒント非依存、Right-aligned/Left-aligned 両対応
  • Float sanity gate による ベンダーデコーダの Float 出力バグ自動検知・フォールバック

2. 96kHz Float32 固定レート DSP パイプライン (CamillaDSP 風)

入力 (任意レート) → RateConverter (Catmull-Rom) → 96kHz Float32 ↓ ┌────┴────┐ │ NativeDspChain │ ├──────────────┤ │ Preamp │ │ Hum Filter (50/60Hz) │ │ Source EQ (Parametric) │ │ Output EQ (Parametric) │ │ Calibration Biquads │ │ Crossfeed (Meier) │ │ Tube Saturation │ │ Ambience (Freeverb + IR) │ │ Soft-knee Limiter │ └──────────────┘ ↓ AudioTrack (96kHz Float32)

特徴:

  • 単一レート処理: 全エフェクトが 96kHz で動作、リサンプルアーティファクト最小化
  • リアルタイムパラメータ更新: updateDsp() で係数再計算しつつフィルタ状態維持
  • IR ベースアンビエンス: アセット同梱 WAV IR (Hall, Jazz Club, Large Hall) を実行時リサンプル
  • 安全クリッピング: Soft-knee (-0.92dBFS) で歪み防止

3. セッション分離・ギャップレス遷移 (SID ベース)

// 毎再生ごとにユニークな Session ID を付与
private static final AtomicInteger SESSION_SEQ = new AtomicInteger(0);
public final int sid = SESSION_SEQ.incrementAndGet();
  • Web 側で古い SID のイベントを破棄 → 競合状態による「操作効かない」「前の曲の位置が残る」を根絶
  • トラック切替時: 旧スレッド即座停止 (haltTrackImmediate() → release()) → 新スレッド起動
  • AudioTrack 再生成: release() でブロック中 write を確実に解放、Huawei 等の HAL バグ回避

4. バックグラウンド/スリープ/Doze 完全耐性

対策 実装
CPU スリープ防止 PARTIAL_WAKE_LOCK (1時間フェイルセーフ)
Wi-Fi スリープ防止 WIFI_MODE_FULL_HIGH_PERF (Android 10+)
プロセス優先度 FOREGROUND_SERVICE_TYPE_MEDIA_PLAYBACK
自動起動 play() 時に ContextCompat.startForegroundService()
通知 継続再生表示 (Ongoing, Silent, Low Priority)

結果: 画面オフ・ポケットイン・省電力モード・Doze モード下でも 全フォーマット途切れなし

5. DSF (DSD) ネイティブストリーミングデコード

  • MediaCodec 不使用: DSD はコーデック非対応のため自前実装
  • ストリーミングパース: ヘッダ 92B 読み取り後、ブロック単位でデシメーション
  • リトライ機構: NAS (Soundgenic 等) のバースト後接続拒否に対応 (3回指数バックオフ)
  • ボックスカー デシメーション: R=32/64/128... で 88.2kHz 以上になる最大 2の冪乗を自動選択
  • 同一パイプライン: デシメート後 96kHz へリサンプル → 共通 DSP → AudioTrack

6. SAF (Storage Access Framework) ネイティブファイル再生

  • 権限不要・システムピッカー経由でローカルフォルダ選択
  • 再帰スキャンで全楽曲取得 (DSF/DFF/FLAC/WAV/MP3/ALAC/APE/WV 等)
  • contentfile エンドポイントで Range Request / Partial Content 対応 → シーク高速
  • アルバムアート: ID3v2/FLAC Picture/MP4 covr/DSF 末尾/フォルダ画像 を多段フォールバック
