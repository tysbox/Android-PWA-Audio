Core Differentiating Features

1. Bit-Perfect Hi-Res Playback (All Formats)

Format Decoder Output Internal Processing Output Bit-Perfect
FLAC/WAV 16bit PCM_16BIT → Float32 normalization 96kHz Float32 OK
FLAC/WAV 24bit PCM_32BIT (Right-aligned 24bit) Auto alignment detect → normalize 96kHz Float32 OK Industry-first equivalent
FLAC/WAV 32bit PCM_32BIT / Float32 Pass-through 96kHz Float32 OK
DSF (DSD64/128) DSD→PCM (Boxcar decimation) 96kHz resample 96kHz Float32 ~ Unavoidable at DSD→PCM
MP3/AAC/OPUS... PCM_16BIT → Float32 normalization 96kHz Float32 OK (Lossless equivalent)

Technical Highlights:

  • convertToFloat32Array() with runtime 24-bit alignment auto-detection (sign-extension heuristic)
  • Independent of srcBits hint, handles both Right-aligned and Left-aligned
  • Float sanity gate for automatic detection/fallback of vendor decoder Float output bugs

2. 96kHz Float32 Fixed-Rate DSP Pipeline (CamillaDSP-style)

Input (any rate) → RateConverter (Catmull-Rom) → 96kHz Float32 ↓ ┌────┴────┐ │ NativeDspChain │ ├──────────────┤ │ Preamp │ │ Hum Filter (50/60Hz) │ │ Source EQ (Parametric) │ │ Output EQ (Parametric) │ │ Calibration Biquads │ │ Crossfeed (Meier) │ │ Tube Saturation │ │ Ambience (Freeverb + IR) │ │ Soft-knee Limiter │ └──────────────┘ ↓ AudioTrack (96kHz Float32)

Features:

  • Single-rate processing: All effects run at 96kHz, minimizing resampling artifacts
  • Real-time parameter updates: updateDsp() recalculates coefficients while preserving filter states
  • IR-based Ambience: Bundled WAV IRs (Hall, Jazz Club, Large Hall) resampled at runtime
  • Safe clipping: Soft-knee (-0.92dBFS) prevents distortion

3. Session-Isolated Gapless Transition (SID-based)

// Unique Session ID assigned per playback
private static final AtomicInteger SESSION_SEQ = new AtomicInteger(0);
public final int sid = SESSION_SEQ.incrementAndGet();
  • Web side discards stale SID events → Eliminates race conditions causing "unresponsive controls" or "previous track position persists"
  • Track switch: Old thread stops immediately (haltTrackImmediate() → release()) → New thread starts
  • AudioTrack recreation: release() reliably unblocks blocked writes, works around Huawei HAL bugs

4. Full Background/Sleep/Doze Resilience

Measure Implementation
CPU Sleep Prevention PARTIAL_WAKE_LOCK (1-hour fail-safe)
Wi-Fi Sleep Prevention WIFI_MODE_FULL_HIGH_PERF (Android 10+)
Process Priority FOREGROUND_SERVICE_TYPE_MEDIA_PLAYBACK
Auto-start ContextCompat.startForegroundService() on play()
Notification Ongoing playback display (Silent, Low Priority)

Result: All formats play uninterrupted under screen-off, pocket mode, battery saver, and Doze mode.

5. DSF (DSD) Native Streaming Decode

  • No MediaCodec: DSD unsupported by codecs, custom implementation
  • Streaming Parse: After 92B header, block-wise decimation
  • Retry Mechanism: Handles NAS (Soundgenic etc.) post-burst connection refusal (3× exponential backoff)
  • Boxcar Decimation: Auto-selects max power-of-2 R=32/64/128... yielding ≥88.2kHz
  • Unified Pipeline: Decimated → 96kHz resample → Common DSP → AudioTrack

6. SAF (Storage Access Framework) Native File Playback

  • Permission-free local folder selection via system picker
  • Recursive scan for all tracks (DSF/DFF/FLAC/WAV/MP3/ALAC/APE/WV etc.)
  • contentfile endpoint supports Range Request / Partial Content → Fast seeking
  • Album Art: Multi-stage fallback (ID3v2/FLAC Picture/MP4 covr/DSF tail/Folder images)

Phone Calibration & Recalibration (AutoEQ-based Acoustic Correction)

🎯 Core feature of this app: Analyzes your headphone's frequency response, then instantly generates the difference between your model and the target curve from a 5000+ entry AutoEQ / oratory1990 database. Applied in real-time on the DSP pipeline.

Correction Curve Formula

// 1. Same profile as target → no correction
if (listening.id === target.id) {
  return { ...listening, bands: [] };
}

// 2. For each listening band:
//    Find a target band at the same frequency (5% tolerance)
//    corrected gain = target gain - listening gain
for (const lb of listening.bands) {
  const tolerance = lb.freq * 0.05;
  const exact = target.bands.find(tb => Math.abs(tb.freq - lb.freq) <= tolerance);
  const targetGain = exact ? exact.gain : 0;
  correctedBands.push({ ...lb, gain: targetGain - lb.gain });
}

UI Operations

  1. SET button: Tap [SET] on the right side of the Phone Calibration card on the mixer panel → drawer opens
  2. Waveform tap toggle: Tap the tone curve at the top of the drawer → toggle listening headphone ⇄ target display (UI only, DSP unchanged)
  3. Calibration Strength: 10-step slider for 0-100% (CamillaDSP's "minimum intervention" philosophy)
  4. A/B Direct: DSP bypass toggle. Instant switch between corrected and raw
  5. 🎯 ターゲットを選択 (Select Target): Choose target curve from catalog or manual input
  6. Preset save: Save calibration settings as a DSP preset
