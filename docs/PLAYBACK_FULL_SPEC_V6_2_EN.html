🚀 1. Core Native NDK & USB Bit-Perfect Direct Pipeline

A 96kHz / 32-bit Float mastering foundation optimized with ARM NEON SIMD, and USB direct E2E bit-perfect output that completely bypasses AudioFlinger.

  • NEON SIMD 96kHz/32-bit Float Pipeline: The complete mastering DSP chain at 96,000Hz / 32-bit Floating Point, parallelized with ARM NEON instructions.
  • Sample-Accurate Gapless Playback Pipeline:
    ・`SinkCarrier` Handover Architecture Retains the output sink (`AudioTrack` / USB Direct) across track boundaries without tearing it down; the successor track appends directly behind the previous track's buffered tail — gapless playback with no silent gaps or noise.
    ・`LookaheadScheduler` Lookahead Prewarm Probes the next track 5 seconds before track completion and pre-initializes the decoder (`PrewarmCache`) in the background.
    ・Fade-Hold Tail Emission A one-chunk hold-back guarantees the true final chunk is faded (up to 3ms / 288 frames, measured 1114-1115 frames) and emitted through the full DSP/sink path — every track ends at exact zero amplitude.
    ・Pause→Flush→Play Handover Re-arm The adopted sink is re-armed via `pause()→flush()→play()`, deterministically clearing residual audio of the previous track.
    ・2-Second Buffer Floor `Math.max(min*4, 1572864)` bytes (196,608 frames ≈ 2.0s) protects the measured worst-case 1.3s park period, eliminating underrun glitches.
  • Dual-Path Absolute Phase Control (0° Normal / 180° Phase Reverse):
    ・DSP ON Mode At the C++/NDK level (`NativeDspChain` - `nativeSetPhaseInverted`), a 1ms cross-fade provides noise-free 180° absolute phase inversion.
    ・DSP OFF (Bit-Perfect) Mode `JavaPhaseInverter` applies 180° phase inversion non-destructively to the raw PCM data right before USB packing, preserving bit depth and sample rate integrity.
  • V6.2Night Mode Dynamics Compressor (`DynamicsCompressor`):
    ・Gentle Feed-Forward RMS Compression 2:1 ratio, −24dB threshold, 20ms attack / 300ms release, −9dB max attenuation floor — calm night listening without pumping artifacts.
    ・~10ms Ramp-Safe Toggle The compression mix ramps over ~10ms (PhaseInverter pattern); toggling can never pop by construction. When disabled, a pure passthrough at zero cost.
    ・Lock-Free & Allocation-Free `setEnabled()` is a relaxed atomic store (safe from any thread); `process()` runs on the audio thread only with no heap allocation.
    ・Bit-Perfect Purity `night: true` is sent only when the Output EQ dial is on NIGHT. The `bypass: true` (bit-perfect direct) path never reaches this branch, so purity is preserved by construction.
  • 4-Point Catmull-Rom Linear-Phase Resampler (`RateConverter`):
    ・Catmull-Rom Cubic Spline Interpolation High-precision resampling of input sources (44.1k/48k/88.2k etc.) to 96kHz.
    ・Linear Phase & Zero Pre-Ringing The time-symmetric 4-point polynomial interpolation kernel achieves a fully linear phase response with zero group delay distortion, completely eliminating pre-ringing (pre-echo) artifacts and faithfully protecting attack transients.
  • USB Direct Output Mode (AudioFlinger Bypass):
    ・DSP OFF (E2E Bit-Perfect Direct) End-to-End bit-perfect direct transmission. The source's native sample rate and original bit depth (16-bit / 24-bit / 32-bit) are delivered to the external USB DAC with zero resampling, zero alteration.
    ・DSP ON (96kHz / 32-bit Mastering & 24-bit Downgrade) Processed through `NativeDspChain` at 96kHz / 32-bit Float precision. If the connected USB DAC does not support 32-bit, it auto-downgrades safely to 24-bit (`UsbPcmPacker`) to match the DAC's hardware limit.
  • Direct NDK Isochronous USB Engine (`UsbDirectEngine`):
    ・Submits USB isochronous URBs (`USBDEVFS_URB_TYPE_ISO`) directly via Linux `ioctl` from the C++/NDK layer — never passing through Android `AudioTrack` or the OS resampler.
    ・Dynamic Kernel Driver Claim & Re-binding On DAC connection, the standard `snd-usb-audio` driver is atomically detached via `USBDEVFS_DISCONNECT_CLAIM`; on release, it re-binds via `USBDEVFS_CONNECT` for fully automated system audio recovery.
    ・UAC1 / UAC2 Descriptor Parsing Parses USB Audio Class 1/2 descriptor structures to auto-detect supported sample rates, channel counts, and bit depths.
  • Triple Output Architecture:
    ・USB Direct Mode USB Isochronous direct output to external USB DACs (DSP off: E2E bit-perfect / DSP on: 96kHz/32bit with 24-bit downgrade).
    ・System Direct Mode Direct playback writing into Android `AudioTrack` (96kHz Float).
    ・HTTP Proxy Mode 32-bit Float PCM delivery via the embedded proxy (`http://127.0.0.1:9600/pcm`).
  • Lock-Free Zero-Allocation Thread: Dynamic memory allocation and lock acquisition are completely eliminated from the audio playback thread, banishing dropouts.
  • True Peak Safety Limiter: 4x oversampled FIR with 1.0ms lookahead physically protects against inter-sample peak (ISP) clipping at the DAC.
  • Hi-Res & DSD/DSF Native Decoder:
    ・DSD (`.dsf`, `.dff`) 1-bit bitstream decoding (`DsfDecoderV2`) plus FLAC, WAV, ALAC, AAC, MP3, M4A multi-format support.
    ・176.4kHz Dynamic Decimation All DSD rates (DSD64/128/256/512) decimate to 176,400Hz hi-res PCM (`decimR` = 16/32/64/128).
    ・Clean Trailing Block Handling Incomplete trailing blocks are safely discarded on `drain()` (verified 0 dirty frames); DSD64 decode measured at 7.81x realtime (t25).

🌙 10. Portable Environment Adaptation (V6.2 — All Features Implemented)

Five major features that automatically adapt to changing mobile environments (DAC connection, network state, thermals, power saving). The purity and robustness of the audio architecture are never compromised.

  • N1Night Mode (Output EQ Dial Integration):
    ・Output EQ Dial Integration The NIGHT position (last, after CRYSTAL) combines the static night EQ curve with the dynamic `DynamicsCompressor` — dial to NIGHT for the complete night listening experience.
    ・Gentle Dynamics 2:1 / −24dB / 20ms-300ms / −9dB floor; ~10ms ramp-safe toggle; lock-free, allocation-free, pure passthrough when OFF.
    ・Stale-State Prevention Every DSP update explicitly applies `night` (false on non-NIGHT positions) — a stale ON state can never survive a dial move (same pattern as the tube reset).
  • N2LUFS Loudness Normalization:
    ・`LoudnessAnalyzer` (pure JVM) Simplified K-weighting approximation (one-pole HPF ~40Hz rumble removal + one-pole high-shelf ~1.5kHz +4dB ear-sensitivity lift + mean-square); `gain = −18 (ReplayGain 2.0 reference) − measured level dB`, clamped ±12dB; silence → 0dB safe default.
    ・End-to-End Trigger Wiring The playback thread collects the first 5s of raw source PCM (copy-only into a preallocated buffer) → analysis runs on the IO pool (R4 respected) → `onLoudnessMeasured` fires exactly once (default method — signature-safe) → rides the existing `playbackTime` channel to the Web layer → `setTrackLoudnessDb()` re-sends the DSP payload, applying the measured gain to the CURRENT track immediately.
    ・Zero New JNI The gain is added to `preampDb` in `updateDspInternal()` — the existing update() path computes `preampLin = 10^(preampDb·cs/20)` at update time (the recomputeMakeup() convention: update-time computation, the audio thread only reads).
    ・Coefficient Bug Fixed by Measurement The initial inverted (decay) coefficient form collapsed the mean square (GainProbe: a 0.95 sine measured +91.7dB = inverted direction); the one-pole step form gives verified correct gains (0.95 → −12 clamped, 0.25 → −10.78, 0.03 → +7.63, 0.0005 → +12 clamped).
    ・Bit-Perfect Purity The bypass payload has `preampDb: 0` and never carries `loudnessDb`, so the USB bit-perfect path is untouched by construction.
  • P1Auto-DAC Profile & Protect System:
    ・`DacProfileStore` (SharedPreferences persistence) VID:PID keying (ports/serials excluded — the same DAC model hits the cache on any port); `load()` returns null on disabled/missing/parse-failure (the caller runs the legacy probe = safe default); `save()` only after a SUCCESSFUL configure+start (a transient failure is never locked in, PrewarmCache semantics); kill switch reverts without a rebuild.
    ・Zero-Latency Re-apply `initUsb()` re-applies the cached bitDepth BEFORE `configure()` (the rate is unchanged — it depends on the source/bypass state, not the DAC).
    ・Soft-Start Anti-Pop Ramp `writeUsbChunk()` ramps gain 0→1 over 8 chunks (~20–50ms), applied to the FLOAT samples BEFORE packing (multiplying packed bytes would corrupt them); armed at 1.0 so the steady state is a single integer compare and the hot path is untouched; the ramp re-arms on every USB (re)configuration — exactly the pop-prone driver (re)bind moment; the AudioTrack path is unaffected (the pop is specific to USB driver rebind). Lock-free: an `AtomicInteger` stepped per chunk on the playback thread only (R4 respected).
  • P2Network-Resilient Variable Pre-roll:
    ・`LookaheadScheduler.setWindowMs()` `windowMs` is now volatile with a 3000–15000ms clamp; the DEFAULT 5000ms is unchanged (the existing tests' contract). A single volatile write — no lock, torn-read-safe, safe from any thread.
    ・`NetworkStateMonitor` `registerDefaultNetworkCallback` (the proven DualSsdpBridge pattern) maps link quality to the window — validated Wi-Fi → 5000ms (legacy default), validated cellular → 8000ms (handover + higher RTT), degraded/unvalidated/lost → 12000ms (a slow open still lands inside the window).
    ・WindowConsumer Pattern The per-listener scheduler is structurally per-track, so the monitor updates a plugin-level volatile field and each new track's scheduler adopts the current window at creation (instance initializer).
    ・Safety Every failure keeps the current window; the kill switch unregisters and restores the default; cold start applies the state immediately; never touches audio paths.
  • P3Thermal & Battery Smart DSP Scaler:
    ・`PowerStateMonitor` `OnThermalStatusChangedListener` (API 29+, guarded) + `ACTION_POWER_SAVE_MODE_CHANGED` receiver; POLICY ONLY — computes a Policy enum and hands it to the consumer; never touches the audio thread, the native engine, or any lock.
    ・Policy Mapping (pure, JVM-testable) Power save → MUTE_AMBIENCE (hard constraint, wins over thermal); thermal ≥ SEVERE → MUTE_AMBIENCE (hard, instant); thermal ≥ MODERATE → REDUCE_AMBIENCE (the gentlest first step: halve the wet level of the single most CPU-hungry stage — the 1024-tap FIR + feedback tail); LIGHT/nominal → NONE (full DSP, exactly the pre-P3 behavior).
    ・Exact Restore on Cooldown `lastUserAmbIntensity` remembers the user's own ambience intensity from each DSP payload, so a thermal reduction restores it exactly when the device cools down.
    ・ZERO New Native Paths The policy is applied through the existing `updateDsp` payload path with a churn guard (no re-send when the change < 0.5); tone shaping, the Night compressor and the limiter are untouched.
    ・Kill Switch (`setEnabled(false)`) unregisters both listeners and notifies NONE — a one-line rollback to pre-P3 without a rebuild (R5 compliant).
